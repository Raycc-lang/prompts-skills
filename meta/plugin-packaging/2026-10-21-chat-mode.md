## Packaging decisions

Three plugins permit independent selection and updates. Package names match their
single included skill names. Each package contains complete source resources and
regular files; no symlinks, outside-package references, app mappings, MCP servers,
credentials, or maintenance records are needed. Existing optional use of tools remains
conditional on the capabilities available in the target chat.

scripts/build_plugins.py derives all copies and manifests from canonical skills and
one metadata table. Its --check mode identifies missing, stale, and unexpected package
files. The repository marketplace exposes only these three packages. A compatibility
manifest also supports clients that expect .codex-plugin/plugin.json.
