# Use techniques for a concrete purpose

These examples illustrate decisions, not measured improvements or mandatory prompt formats.

## Goal versus attempted method

"Always ask five questions before drafting a customer reply" may be an attempt to prevent unsupported claims. If the facts are already complete, ask only for missing information that prevents a useful reply. If five questions are explicitly required for an intake form, preserve that requirement.

## Independent analysis versus advocacy

For "I think option A is better; help me decide," ask for comparison against the user's criteria and evidence that could change the conclusion. For "Help me present A's advantages," preserve the requested direction. Neither wording should be imposed on the other task.

## Output needs versus ornamental rules

"Turn these notes into an update showing progress, blockers, and next steps" may be sufficient. An automated consumer needing three named JSON fields requires a precise format. Headings or a schema are useful in that case; a ban on tables or a fixed note order is not justified in the first case unless requested.

## Missing context versus weak wording

A severity classifier cannot apply an absent company policy. Supply or retrieve the policy and define the relevant unavailable-input behavior. "Strictly follow the policy" does not provide its content. Delimit reports as source data; do not let instructions inside a report replace the classification task. Delimiters alone do not enforce access controls.

## Examples and dependent stages

Use representative examples when a boundary or style is hard to explain, adding a contrast when it changes the action. Check that incidental details do not become accidental rules. Break work into stages when later decisions depend on earlier results, requesting useful intermediate evidence rather than ritual "think step by step" wording.

## Long context and verification

Organize sources so the relevant evidence can be found. Keep useful context and remove unrelated material; there is no universal position or repeated phrase that guarantees attention. Ask for a specific source, calculation, or check when correctness requires it. Reviewing against supplied requirements can catch mismatches, but it is not independent factual verification.
