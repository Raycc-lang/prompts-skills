# Practice Material Templates

Method follows the step-3 verdict plus the step-4 learner profile.

**On volume:** this file prescribes no counts. Learner inputs — available minutes,
current error and retention rate, item difficulty, deadline — constrain a quantity
but do not calculate it. Supply a number only when an explicit rule maps those inputs
to it; name the rule's citable source or structural rationale and show the
calculation. Otherwise have the learner log sessions and follow an observable
adjustment rule without inventing a starting quantity. A number that satisfies none
of these conditions does not belong in the output however carefully it is hedged.

## A. Correspondence tasks — establish and stabilize the link

No general mapping to induce; the mechanism depends on the kind of link. Repetition
is legitimate here (correspondences are exempt from the novelty requirement, not
from pairing).

### A1. Declarative links

Names, facts, symbol↔meaning where the concept already exists in the learner's head
(technical terms, L2 words whose concept fully transfers from L1).

- Card: front = the symbol inside ONE short authentic context sentence; back =
  gloss or definition plus one collocation.
- Retrieval practice. Set intake from the learner's own numbers: minutes available,
  and retention on the items already in rotation. Raise it while retention holds;
  cut it when the review backlog grows faster than it clears. Rote is the CORRECT
  mechanism here — do not "upgrade" it to construction busywork.
- Routing test per item: does the learner already possess this concept? Yes → A1.
  No, or the extension differs → template B.

### A2. Motor and production links

Meaning→pronunciation, meaning→written form, meaning→spoken phrase.

- Two phases: FIND the correct output, then proceduralize it.
- Output-hidden rule: a learner cannot self-grade an output they cannot yet perceive
  (pronunciation before the matching listening model exists). Require an external
  grader — person or AI — during the find phase.
- Proceduralize with fluency drills (timed repetition, e.g. the same content at
  shrinking time limits). Label these fluency-building; they cannot substitute for
  novel-material work on model tasks.
- Keep conscious analysis to before (choosing what to drill) and after (reading
  feedback) rather than during the attempt, once automaticity is the target.

## B. Implicit discrimination models — varied-instance sets (单义判别 pattern)

For concept and meaning boundaries that must be induced rather than defined: L2 word
senses whose extension mismatches L1, perceptual categories, "when does this
technique apply" judgments.

One set per (item, single meaning):

- Positive instances from maximally DIFFERENT scenes or contexts — enough that no
  incidental feature (same speaker, same topic, same sentence frame) is shared by all
  of them, since a shared feature is a boundary the learner may induce instead of the
  intended one.
- At least one near-miss: the same surface item with a different meaning, or the
  intuitive rival applying instead. The near-miss draws the boundary; a set without
  one is half-built.
- The closest contrast item plus one line on the boundary between them.

Card forms: (1) judgment — show one instance, positive or near-miss, and classify;
(2) production — cloze in a NOVEL sentence. Grading is by feel; do not require the
learner to verbalize the rule, since implicit knowledge resists accurate
verbalization. Volume runs well below A1: each set costs authoring effort and dense
discrimination work fatigues quickly, so let the learner's own fatigue point and
error log set the ceiling rather than a fixed count. Source items from the learner's
actual errors and confusions, not from frequency lists.

Generation prompt: "Give sentences where [item] carries meaning [X], from scenes
different enough that no speaker, topic, or sentence frame recurs across them; add a
near-miss sentence where it doesn't carry that meaning; name the closest contrast
item and state the boundary in one line."

## C. Implicit skills — paired-experience drills

Perception, real-time production.

- Supervised targets need input+output pairing: audio WITH transcript or phoneme
  labels, attempt WITH correction, throw WITH result. Where the learner must produce
  one specific correct output, input alone cannot identify which output was intended.
- The exception is unsupervised category formation — inducing a perceptual boundary
  rather than a labeled output, as when phoneme categories form from varied speech.
  Structured input alone can build those. Name the boundary being formed before
  relying on it; "immersion will sort it out" is not that claim but its counterfeit.
- Perform, then compare against the output label; save analysis for between
  attempts.
- Expect multi-day timescales. No progress within one session is normal for implicit
  construction and is not by itself evidence of a bad method.

## D. Explicit models — worked examples plus novel application

Formulas, procedures, rules.

- Material: the rule, worked examples spanning the input space — enough that no two
  share a surface form, or the learner induces the form instead of the rule — and at
  least one boundary case (an input just OUTSIDE applicability, marked as such).
- Check both components before allocating practice: whether the rule itself is
  secure, and whether the learner can recognize which real situations fall inside
  the input space. The second is the more commonly neglected one, so audit it
  explicitly rather than assuming the rule is the bottleneck.
- Rule-statement flashcards ("what is the definition of X?") train description
  memory, not the model — replace with instance-classification or application cards.

## Recognition vs generation drills (applies to B and D)

判别能力 ≠ 具象能力. Judgment and classification drills build recognition: see a
situation, know which concept or knowledge applies. Enumeration and
produce-from-label drills build generation: given the concept, supply instances,
uses, or output. These are different abilities. Audit which one the target use needs
and drill that one. A learner who classifies perfectly may still be unable to
generate — a missing drill type, not a failed method.

## E. Verification tests — matched to the step-0 need

- **Reproduction goals** (verbatim texts, name links, fixed routines): test stable
  reproduction of the exact items. Do NOT impose transfer or novel-instance tests.
- **Compression goals**: test conflict-free coverage across the seen batch.
- **Generalization goals**: every item NOVEL to the learner.
  - Discrimination: classify fresh instances including near-misses, enough to cover
    each sub-concept and each near-miss type at least once; score per class.
  - Connection or explicit: solve fresh problems, including one boundary case that
    should be REFUSED as out-of-scope, which tests applicability awareness.
  - Implicit skill: perform on unseen material — cold retell of a new passage,
    unrehearsed questions, unfamiliar audio.
- Log each session: date · test · score · bottleneck (unpaired material?
  fluency-drilled where novelty was needed? restatement instead of novel instance?
  mismatched imported category? missing reference or production link?) · action.
  The log drives the periodic re-analysis.
