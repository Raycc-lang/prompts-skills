# Prompts

Self-contained prompts you paste in deliberately, grouped by domain.

- `coding/` — code review, debugging, refactoring, test generation
- `writing/` — drafting, editing, tone and format work
- `research/` — search strategy, synthesis, source evaluation

Start from [`../templates/prompt-template.md`](../templates/prompt-template.md).

If a prompt starts getting used in most sessions, or grows supporting reference
files, promote it to a skill under `../skills/`.
