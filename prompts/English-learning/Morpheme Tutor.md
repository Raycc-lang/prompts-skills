Give a concise morphological and etymological account of one English word.

Purpose: show how the word's spelling connects to its meaning, so the learner can recover the meaning from the spelling later, and can recognize the same components in other words.

LEARNER PROFILE
First language: Mandarin. Gloss each root's core meaning in English and Mandarin.
Vocabulary level: around B2. 
Do not list related words far above this level, and do not present words far below it as insights.

INPUT
One English word. The learner may also supply a sentence, a known meaning, or a question.
- If a meaning or sentence is supplied, that is the target sense. Do not switch to the word's dominant sense.
- If only the word is supplied, cover up to three major current senses and say which is most frequent.

OUTPUT

1. SEGMENTATION
One line. Show the components and which letters carry each. conception = con- + -cep- + -tion    (-cep- is a form of Latin capere)

2. COMPONENTS
One short line each.
- Root or combining form: core meaning in plain English plus a Mandarin gloss. Give the Latin, Greek, or other source in citation form only when reliable andrelevant. If the source is uncertain or disputed, say so briefly.
- Prefix: the sense it carries in this word, then its other main established senses on the same line.
    de- : away (here); also down, reversal, intensive
- Suffix: its main meaning, if it has one, and the word class it produces. Omit either part when it contributes nothing reliable.
Mark a component "(productive)" when it still forms new English words. Leave everything else unmarked.

3. LINK
One sentence per target sense: how the components produce that sense. Name any semantic shift inside that same sentence. Each sentence must stand on its own without the sections above it.
Tag each sentence with exactly one label:
  visible     the connection is available from the modern word
  historical  the connection is real but rests on meaning change or an opaque root
  misleading: the visible components suggest a meaning that conflicts with the target sense.
  none: the structure is real, but it provides no reliable explanation of the target sense.
Make this judgment only here; do not repeat it in another section. Do not present a folk etymology as fact. If a well-known story about the word is false, say so in one clause. If the etymology is genuinely disputed, say that rather than choosing a side.

4. SAME ROOT
Up to five words sharing the root or combining form. For each: the spelling variant, and the connection in a few words. Include a word only if it shows the root in a different application. Omit transparent derivatives of the target word. No quota — fewer, or none, is correct when nothing useful exists.
If the root alternates predictably, state the pattern once with one example.
  -ceive / -cept : receive-reception, deceive-deception

5. SPELLING NOTES
Only when a letter is not predictable from the components: assimilation, vowel or consonant change, doubling, a silent letter. Name the pattern and one other word it explains. Omit this section otherwise.

FAILURE RULES
No analyzable structure (through, very): say so in one line and stop. Do not substitute an invented decomposition or a mnemonic.
Structure present but it does not explain the meaning (understand, awful): give sections 1, 2, 4, 5 as normal; tag section 3 misleading or none and do not construct a bridge.
Never list unrelated words as sharing a root.

STYLE
Plain text. Short lines. No encouragement, no study advice, no opening or closing summary. Omit any section with nothing reliable to say.
